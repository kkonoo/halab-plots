# HaLab Plots

https://kkonoo.github.io/halab-plots/

Resize our R figures (ggplot, pheatmap, ComplexHeatmap, base R plots such as corrplot) for a paper and download them (PDF, SVG, TIFF, PNG, JPG), together with the data table behind each figure.
Figures are drawn by R running inside your browser ([webR](https://docs.r-wasm.org/webr/)), so there is nothing to install.

Open it with the project link you were given.
